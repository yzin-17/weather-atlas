# Flutter 流式天气对话

## 目标与边界

Flutter 使用 `ai_ui_stream` 接入 Web 已有的 `/api/ask` UI Message Stream v1。保留服务端意图校验、数值计算与凭据配置；客户端不直接调用模型。当前任务只调整移动端对话和相关验证，不改动正在进行的其他项目工作。

## 行为

- 同一会话保留历史；首次提问后隐藏推荐问题。发送立即清空输入，失败仅在草稿未编辑时恢复。
- SSE 展示天气准备、搜城与模型处理阶段。收到文本后按 Unicode 字素逐字显示；减少动态效果设置下直接显示。停止同时取消网络请求和本地显示，部分回答不展示完整依据。
- 手动重试复用最后问题，不重复添加用户消息，不自动追加模型调用。409 先刷新当前及上下文城市版本，保留日期锚点，再重试。
- 单城市和双城市追问传递各自上下文，依据打开对应城市、时区与天气快照。切换当前页面城市建立新会话。
- 使用现有四种语言，保留未知降水概率。请求只发送问题、地点、版本和有限上下文，不上传整个历史。

## 验收

通过协议、控制器和界面测试验证分片、断流、错误、取消、重试、草稿、逐字显示与城市依据。运行 Flutter 静态检查及全量测试，在可用 Android 和 iOS 模拟器执行原生集成测试并构建调试产物。记录真实模型与受控样本的区别，不将模拟器结果视为真机验收。
