# 指定城市的单城天气问答

## 范围与约定

- AC1：在其他城市页面输入“今天广州天气怎样”，服务端解析并校验城市，以广州当地日期读取广州天气，回复标明城市与时区。
- AC2：继续询问“明天呢”“那下午呢”“会下雨吗”，保留城市，只更新明确改变的日期、时段或指标。明确改问另一城市或当前地点时切换依据；切换页面后上下文失效。
- AC3：回答依据绑定目标城市、快照版本和当地日期。小时或日期依据可在 Web 弹窗查看对应城市预报，不跳到页面原城市。
- AC4：模型只提取城市与查询意图，天气数值由服务端计算；无密钥规则模式支持明确模板。城市歧义、无结果、缺测和版本过期均不猜测；409 可刷新后重问。
- AC5：保留原有当前城市与双城比较入口。测试、构建后更新现有 HTTP／HTTPS 服务，使用已有本地凭据验证真实模型，不提交凭据。

## 接口与取舍

复用 `/api/ask`。增加独立 `singleContext` 和 `singleForecast`，不改变双城 `context` 的含义。服务端重新解析上下文城市并校验版本，客户端只负责传回上下文及展示依据。本次目标界面为用户截图中的 Web 问答弹窗；不新增原生客户端发布任务。

## 验收

服务端回归覆盖全球搜索、四语、追问、换城、跨午夜、非法上下文、409、歧义与缺测；浏览器覆盖真实模型三轮、对应城市依据及生产服务检查。证据与取舍记录见 `../../qa/SINGLE-CITY-ASK.md`。
