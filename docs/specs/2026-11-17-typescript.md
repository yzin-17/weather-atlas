# TypeScript 迁移

## 目标与范围

将自有 Web 源码、Node 测试、QA 和格式化工具中的 JS／JSX／MJS 转为 TS／TSX，补全地点、天气快照、AI 查询与组件契约。第三方依赖、历史证据、生成文件和 Flutter 的 Dart 保持其原始格式。

## 实现约束

- 使用严格类型检查；生产构建必须通过类型检查。
- 外部数据保留运行时校验，类型声明不能代替校验。
- Node 脚本使用原生类型擦除，要求 Node 22.18 或更新版本，不增加运行时转译依赖。
- 保留已有本地改动、凭据、天气缓存、AI 行为、SEO 与地图按需加载。
- 更新可执行命令、源码引用和交付工具，历史验收数据保留实际来源。

## 验收

严格类型检查、Node 回归和 Next 生产构建通过；在受控天气上游与禁用真实模型凭据的独立实例检查城市页、地图、定位与 AI 对话，最后更新取舍记录和源码包。
