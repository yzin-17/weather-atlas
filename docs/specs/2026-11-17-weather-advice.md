# 天气问答范围扩展

## 目标与边界

用户要求扩充现有预设问题，直接触发案例为“今天广州天气怎样 → 出门穿什么衣服”。沿用服务端意图提取和天气计算，不增加正常提问的模型调用次数；以当前已有温度、降水概率、天气现象生成四语建议。风速、湿度、空气质量及紫外线指数当前未采集，不推测这些读数或相关等级。

## 验收约定

- AC1：增加穿衣、户外活动（跑步／骑行／出游）、晾衣、防晒／紫外线数据可用性和天气现象查询；每日概述包含天气现象与温度。建议的数值来自对应快照，解释选用范围。
- AC2：指定其他城市后追问保留城市、当地日期和时段；从每日预报切到生活建议时保持原日期，明确日期／时段覆盖继承值。缺失降水不当作零，不输出缺少依据的天气肯定判断。
- AC3：真实模型模式与无密钥规则模式均支持新意图；模型只提取计划，建议由服务端计算。原有双城、版本冲突、SSE、逐字显示及停止保留。
- AC4：回归测试、四语浏览器、真实模型定向路径、生产构建和运行服务验证；记录模型次数、事实／建议边界及未覆盖字段。
